# Subtle Sync

A glowing interactive 3D visualization built with [Astro](https://astro.build), [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/), and [Three.js](https://threejs.org/).

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Build

Build for production:

```bash
pnpm build
```

Preview production build:

```bash
pnpm preview
```

## Features

- Interactive 3D visualization with mouse controls
- Double-tap for fullscreen mode
- Responsive design with Tailwind CSS
- Built with Astro for optimal performance

## Tech Stack

- **Framework**: Astro
- **3D**: React Three Fiber, Drei, Three.js
- **Styling**: Tailwind CSS
- **Package Manager**: pnpm
